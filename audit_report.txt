Audit Report
============

Date: audit de la branche auto_code_412 (projet mw-swarm)

Résumé
------
L'audit du codebase a révélé plusieurs problèmes fonctionnels et de
cohérence. Contrairement au rapport précédent (qui indiquait "no issues"),
plusieurs défauts ont été identifiés lors de la revue détaillée.

Issues détectés
---------------

### 1. [CRITIQUE] Streaming non fonctionnel
- Fichier source : findings.txt
- Le streaming n'est PAS fonctionnel : le provider limite tous les flux
  avec `finish=stop`. Aucune réponse n'est réellement streamée.
- Impact : les réponses sont générées en bloc au lieu d'être diffusées en
  temps réel (SSE/streaming cassé).
- Recommandation : corriger la logique de streaming du provider.

### 2. [MAJEUR] 9 panels "agents" non implémentés
- Fichier source : audit_agents.md
- Les panels suivants n'ont AUCUN fichier lié dans le dépôt :
  - agents-activity (V2 natif, bundle Core)
  - agents-composition-equipe (V1 externe)
  - agents-equipe-leger (V1 externe)
  - agents-equipe (V1 externe)
  - agents-lanceur (V1 externe)
  - agents-liste (V1 externe)
  - agents-monitoring (V2 migré, bundle Core)
  - agents-team-members (V1 externe)
  - agents-topologie (V1 externe)
- Impact : rôles affichés "Non déclarés", aucun fichier d'audit associé.
- Recommandation : implémenter et déclarer ces panels.

### 3. [MAJEUR] Panels "gestion" : rôles attendus vs affichés incohérents
- Fichier source : audit_gestion.md
- gestion-catalogue-modeles : rôle attendu admin, affiché viewer
- gestion-cles-api : rôle attendu developer, affiché user
- gestion-outils : rôle attendu admin, affiché user
- installator-* : rôle attendu admin, affiché user
- Impact : risque de sécurité / mauvaises permissions (élévation ou
  restriction incorrecte des rôles).
- Recommandation : aligner les rôles affichés sur les rôles attendus.

### 4. [MOYEN] Panels "système" : rôle affiché non vérifié
- Fichier source : audit_systeme.md
- 6 panels (systeme-dashboard, systeme-etat, systeme-llm-locaux,
  etat-systeme, gestion-bundles, gestion-panneaux) sont listés avec des
  rôles attendus mais sans vérification du rôle réellement affiché.
- Recommandation : compléter l'audit de cohérence des rôles.

### 5. [MOYEN] Conflit git non résolu (historique)
- Fichier source : problemes_detectes.md
- Le fichier audit_report.md contenait des marqueurs de conflit git non
  résolus (`<<<<<<< HEAD`, `=======`, `>>>>>>>`).
- Statut : corrigé (conflit résolu, branche corrigée auto_code_435 ->
  auto_code_412).

### 6. [INFO] Multiplicité de rapports d'audit redondants
- De nombreux fichiers de rapport coexistent (audit_report.md,
  audit_reports/, rapport_audit.md, audit_report_issues.md, etc.) avec des
  contenus parfois contradictoires (certains affirment "no issues").
- Recommandation : consolider les rapports en une source unique.
